# grace-chapel-audio

은혜의 뜰 온라인 예배당의 말씀 음성 파일 모음입니다.

| 파일 | 주제 | 내용 |
|---|---|---|
| tired.mp3 | 지칠 때 | 마태복음 11:28-29, 시편 23:1-3 |
| anxious.mp3 | 불안할 때 | 빌립보서 4:6-7 |
| lonely.mp3 | 외로울 때 | 신명기 31:6, 이사야 43:1-2 |
| sad.mp3 | 슬플 때 | 시편 34:18, 요한계시록 21:4 |
| words.json | 문장 시간표 | 파일마다 문장이 시작하는 시간(초)과 본문 |

## 깃허브 페이지에 올리는 법
1. 깃허브에서 새 저장소를 만든다. 이름은 `grace-chapel-audio`, 공개(Public)로 둔다.
2. 이 폴더 안의 파일 5개(mp3 4개, words.json)를 저장소 맨 위(루트)에 올린다. 웹에서 끌어다 놓으면 된다.
3. 저장소 Settings → Pages → Branch를 `main`, 폴더를 `/ (root)`로 두고 저장한다.
4. 몇 분 뒤 `https://깃허브아이디.github.io/grace-chapel-audio/tired.mp3` 주소를 브라우저에 붙여 넣어 소리가 나오면 성공이다.
